# Missing art: image prompts

71 images.

Prompts for the art still missing from Mossling. Each block is a complete, self-contained prompt: copy one block per image.

## Tips for consistency

- **Use a reference image.** Attach `src/assets/img/pet/sprig/sprig_idle.png` (or the Sprig/Dewdrop pose closest to the one you're making) so the style, lighting and eyes match.
- **Make each form's `idle` first**, then attach that `idle` image as the reference for the form's other 12 poses ("same character, same size, same position").
- **Name files exactly** as the headings below and upload them to `src/assets/img/pet/<form>/` (or `src/assets/img/props/`). PNG is fine; I'll convert them.
- **Check the feet line**: the lowest point of the character should sit about 88% of the way down the image, the same as your Sprig and Dewdrop art. `npm run assets:check` flags any that are off.
- Generate a form at a time; that's 13 images per form.
